# Modern source-available and cloud-era licensing

This family covers modern licences and licence add-ons that make source code visible but place use restrictions that may prevent classification as open source or free software.

## Scope

This family covers:

- Business Source License;
- Server Side Public License;
- Elastic License;
- Commons Clause;
- PolyForm licences;
- Functional Source License;
- other open-core, cloud-restriction, delayed-open-source, and source-available models.

## Research questions

- Which modern licences are open source, and which are source-available only?
- How do cloud-service restrictions compare with older Unix source-access arrangements?
- Which licences use delayed conversion to open source terms?
- How do modern source-available models differ from GPL/AGPL network-use copyleft?

## Collection policy

Use vendor or licence-steward sources as primary sources. Clearly distinguish open source, free software, source-available, and proprietary source-access models.
