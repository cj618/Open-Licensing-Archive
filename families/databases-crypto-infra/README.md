# PostgreSQL / Sendmail / OpenSSL / infrastructure

This family covers long-lived infrastructure licences and notices that shaped Unix-like systems, internet services, databases, mail, cryptography, and server software.

## Scope

This family covers:

- PostgreSQL licence material;
- Sendmail licence variants;
- OpenSSL and SSLeay licensing;
- other historically significant infrastructure licences not better placed in Apache, BSD, GNU, or language-specific families.

## Research questions

- Which infrastructure projects used permissive terms, and which had special advertising or attribution requirements?
- How did OpenSSL/SSLeay licensing interact with GPL compatibility concerns?
- How did PostgreSQL's permissive licence relate to BSD-style licensing and database commercialisation?

## Collection policy

Use official project pages where available. Preserve older source-tree notices separately when they differ from current project licence pages.
