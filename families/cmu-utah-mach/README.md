# CMU / Mach / University of Utah / Flux / OSKit

This family covers operating-system research licensing in the Mach, BSD-derived, and Utah Flux traditions.

## Scope

This family covers:

- CMU Mach notices;
- Lites and BSD/Mach research material;
- University of Utah Flux and OSKit licensing;
- operating-system research code that influenced Unix-like systems, microkernels, and later platforms.

## Research questions

- Which notices apply to Mach components used in NeXT, Darwin, and other systems?
- Which parts are CMU-origin, UC Regents-origin, Utah-origin, or third-party?
- How did OS research licensing differ from commercial Unix source access and GNU copyleft?

## Collection policy

Use source-tree provenance wherever possible. Avoid flattening Mach/BSD/Utah material into a single generic permissive licence; the historical value is in the exact notices and component lineage.
