# IBM / Eclipse / CPL / EPL

This family covers IBM's corporate open source licensing work and the Eclipse Foundation lineage.

## Scope

This family covers:

- IBM Public License;
- Common Public License;
- Eclipse Public License 1.0;
- Eclipse Public License 2.0;
- Jikes and other historically significant IBM source releases.

## Research questions

- How did IBM's open source licensing respond to corporate patent and contribution concerns?
- How did CPL evolve into EPL?
- How did the Eclipse Foundation model influence later corporate-backed open source governance?

## Collection policy

Use Eclipse Foundation and OSI/SPDX materials as baselines for CPL/EPL texts. Track IBM project-specific source releases separately where they show historically important terms or notices.
