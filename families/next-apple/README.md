# NeXT / Apple / Darwin / APSL

This family covers the licensing history around NeXT, Mach/BSD-derived commercial workstation systems, Apple Darwin, and the Apple Public Source License.

## Scope

This family covers:

- NeXTSTEP and OpenStep source and licensing context;
- Darwin source releases;
- Apple Public Source License versions;
- Apple open source release notices;
- Mach/BSD-derived platform licensing where relevant.

## Research questions

- How did NeXT's Mach/BSD lineage carry into Apple's Darwin releases?
- What changed between APSL versions?
- How did APSL differ from BSD, GPL, MPL, CDDL, and later corporate open source licences?
- Which Apple open source components use third-party licences rather than APSL?

## Collection policy

Use Apple Open Source and Apple APSL pages as primary sources for Apple-published licence material. Treat NeXT-era documents conservatively until provenance and redistribution status are checked.
