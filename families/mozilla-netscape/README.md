# Mozilla / Netscape

The Mozilla and Netscape licensing family is central to the history of corporate source releases and file-level copyleft.

## Scope

This family covers:

- Netscape Public License;
- Mozilla Public License 1.0;
- Mozilla Public License 1.1;
- Mozilla Public License 2.0;
- historical Netscape Communicator and Mozilla source-release material.

## Research questions

- How did Netscape's source release differ from GNU and BSD traditions?
- How did MPL-style file-level copyleft influence later corporate open source licences?
- How did MPL 2.0 simplify or modernise earlier Netscape/Mozilla terms?

## Collection policy

Use Mozilla's current licence pages for canonical modern MPL texts. Treat early Netscape release material separately and preserve source-release context where available.
