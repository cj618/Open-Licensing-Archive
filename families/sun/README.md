# Sun Microsystems / Solaris / OpenSolaris / Java

Sun is central to corporate Unix and corporate open source history. Its licensing story moves from workstation Unix and network computing through Java, the Sun Public License, CDDL, and OpenSolaris.

## Scope

This family covers:

- SunOS and Solaris licensing context;
- Sun RPC and network-computing notices;
- Sun Public License;
- Common Development and Distribution License;
- OpenSolaris source-release material;
- Java-related source licensing where historically relevant.

## Research questions

- Which Sun materials were permissive, which were weak copyleft, and which were source-available or proprietary?
- How did CDDL relate to MPL-style file-level copyleft?
- How did OpenSolaris licensing differ from community BSD, GNU, and Linux licensing traditions?
- Which Java source-release licences should be treated as software-freedom licences, and which were compatibility or platform-control instruments?

## Collection policy

Use official Sun/Oracle, OpenSolaris, OSI, SPDX, and FSF sources where possible. Treat historical Sun source materials as separate entries rather than collapsing them into CDDL alone.
