# Perl / Python / Tcl/Tk / Ruby

This family covers language-runtime and scripting-language licences that shaped the practical open source ecosystem of the 1990s and 2000s.

## Scope

This family covers:

- Artistic License versions;
- Perl dual-licensing practice;
- Python licence variants;
- Tcl/Tk licensing;
- Ruby licensing;
- language-runtime notices and contribution/licensing transitions.

## Research questions

- How did Perl's dual GPL/Artistic licensing operate in practice?
- Which Python versions used which licence texts?
- How did permissive language-runtime licensing support Unix-like scripting culture?
- Which language licences were OSI-approved, FSF-free, or GPL-compatible?

## Collection policy

Use official project documentation for canonical language licence texts. Source-tree notices should be preserved where they clarify version-specific licensing.
