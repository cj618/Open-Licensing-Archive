# GNU / Free Software Foundation

The GNU family is central to the free software and copyleft licensing tradition. It is also historically inseparable from proprietary Unix, because GNU licensing developed in direct response to restrictions on software sharing, modification, and redistribution.

## Scope

This family covers:

- GNU General Public License versions;
- GNU Lesser General Public License versions;
- GNU Affero General Public License;
- GNU Free Documentation License;
- FSF licence exceptions;
- source-tree notices in GNU projects where historically important.

## Research questions

- How did GPLv1, GPLv2, and GPLv3 respond to different historical problems?
- Which early GNU programs used program-specific notices before licence standardisation?
- How did LGPL and special exceptions support libraries, toolchains, and language ecosystems?
- How did GNU licensing influence Linux, BSD projects, commercial Unix replacements, and corporate open source?

## Collection policy

GNU licence texts are available from the GNU Project and should be treated as canonical for modern licence entries. Historical source-tree notices should still be captured separately where they show important differences in wording, timing, or project practice.
