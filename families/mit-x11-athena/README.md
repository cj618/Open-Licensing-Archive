# MIT / X11 / Athena / Kerberos

This family covers permissive university and network-computing licences associated with MIT, X11, Athena, Kerberos, and related systems.

## Scope

This family covers:

- MIT/X11 licence texts;
- Project Athena notices;
- X Consortium and X.Org licensing material;
- Kerberos licensing material;
- MIT-derived permissive source-tree notices.

## Research questions

- Which texts are properly MIT, X11, X Consortium, or project-specific variants?
- How did MIT/X11 licensing influence later permissive licences?
- How should the archive represent short-form modern MIT licence text versus historical X11 wording?

## Collection policy

Use SPDX as a baseline for modern identifiers, but preserve historical source-tree wording separately where it differs.
