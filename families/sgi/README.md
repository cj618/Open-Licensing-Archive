# SGI / IRIX / XFS / Open Inventor

This family covers Silicon Graphics licensing material, especially around workstation Unix, graphics, XFS, and source releases.

## Scope

This family covers:

- SGI Free Software License variants;
- XFS source-release licensing;
- Open Inventor licensing;
- IRIX-related source availability where historically relevant;
- graphics and workstation ecosystem licensing material.

## Research questions

- Which SGI releases used OSI-approved terms, and which did not?
- How did SGI licensing differ across XFS, Open Inventor, and other released components?
- How did SGI source releases fit into the late-1990s workstation-to-Linux transition?

## Collection policy

Use SPDX, OSI, FSF, SGI historical material, and source releases as baselines. Treat old vendor source releases carefully where redistribution status is unclear.
