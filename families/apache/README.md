# Apache / NCSA / web infrastructure

The Apache family is central to permissive open source infrastructure licensing, especially for web servers, middleware, and later corporate open source projects.

## Scope

This family covers:

- NCSA-style licensing;
- Apache License 1.0;
- Apache License 1.1;
- Apache License 2.0;
- Apache contributor and notice practices;
- patent grant and patent termination language in Apache-2.0.

## Research questions

- How did Apache licensing evolve from earlier permissive web-server licensing?
- How did Apache-2.0 normalise explicit patent language in permissive corporate open source?
- How did Apache notice-file practice influence later project governance?

## Collection policy

Use Apache Software Foundation materials as primary sources for Apache licence texts. Use source-tree examples to record historical adoption and notice-file practice.
