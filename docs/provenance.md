# Provenance policy

This archive is only useful if every entry is tied to a source that can be checked.

## Attribution

Project maintainer attribution, where needed:

**C. R. Jervis - chrisxjervis@gmail.com**

Do not add informal, automated, or tool-generated attribution strings to archive entries. Attribution should identify the archival maintainer, the original licence steward, and the source of the document.

## Source priority

Use sources in this order:

1. Original licence steward or publisher.
2. Original source tree, release tarball, manual, README, copyright file, or vendor release.
3. Official project, vendor, university, foundation, or standards-body archive.
4. Internet Archive, Software Heritage, historical mirrors, or court-record repositories.
5. SPDX, OSI, FSF, Debian, Fedora, ScanCode, or other structured licence databases.
6. Reputable historical secondary sources.
7. Unverified mirrors, only as leads.

## Required checks before adding full text

Before adding full licence text, check:

- whether the text is itself redistributable;
- whether the version is canonical or merely a source-tree variant;
- whether a later SPDX text differs from the historical version;
- whether the original document contains copyright, confidentiality, evaluation-only, research-only, export, or no-redistribution language;
- whether the entry should be metadata-only.

## Conservative treatment of historical Unix material

Many early Unix documents are historically important but may not be suitable for full-text republication without further review. Treat the following as metadata-only unless a clear redistributable primary source exists:

- AT&T / Western Electric / Bell Labs source agreements;
- UNIX System Laboratories agreements;
- Novell/SCO/Caldera agreements and dispute material;
- old proprietary workstation vendor source agreements;
- evaluation, educational, research-only, or confidential source licences.

## Metadata-only entries

A metadata-only entry should still be useful. Include:

- title;
- family;
- likely date range;
- organisation;
- source pointers;
- historical significance;
- uncertainty notes;
- why full text is not included;
- next verification step.

## Source notes

Every source note should answer:

1. What is this document?
2. Who published it?
3. When was it published or first known?
4. Where was it found?
5. Is it canonical, a variant, or commentary?
6. Can the archive reproduce it?
7. What should be checked next?
